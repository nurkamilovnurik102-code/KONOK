# Как объяснить KONOK KG учителю

## Короткая презентация (5 минут)
1. **0:00–0:40 — проблема:** туристу сложно найти в одном месте историю памятника, расположение, экскурсию и подготовку к поездке.
2. **0:40–1:20 — решение:** KONOK KG объединяет 7 областей, исторические объекты, карту, демоэкскурсии и товары мастеров.
3. **1:20–2:20 — интерфейс:** показать Hero, области, каталог, фильтр, карточку памятника и карту. Указать, что 3D-модуль подгружается и может отключаться при сниженной анимации.
4. **2:20–3:20 — React и API:** React Router управляет страницами, компоненты переиспользуются, `request()` делает fetch к Express, Prisma читает PostgreSQL.
5. **3:20–4:20 — заказ:** регистрация → товар и экскурсия → корзина → checkout → сервер проверяет цену и остаток → заказ в базе → админка. Платёж демонстрационный.
6. **4:20–5:00 — админка и развитие:** роли JWT, редактирование контента, музыка природы, Telegram/WhatsApp, планы на AI-гид.

## Ответы на возможные вопросы
- **Что такое React?** Библиотека для декларативного построения интерфейсов из компонентов.
- **Что такое useState?** Хук для локального состояния (количество гостей, фильтры, формы).
- **Что такое useEffect?** Хук для синхронизации с внешними системами, например загрузка данных или работа аудио.
- **Что такое props?** Входные параметры компонентов, например название и изображение карточки.
- **Зачем React Router?** Отображать разные страницы без полной перезагрузки.
- **Зачем TypeScript?** Проверять типы данных и сокращать ошибки при разработке.
- **Что такое REST API?** HTTP-интерфейс для данных; GET читает, POST создаёт, PATCH изменяет.
- **Что такое Prisma?** ORM для доступа к PostgreSQL через модели.
- **Зачем JWT?** Подтверждает вход и роль; сервер проверяет токен для защищённых запросов.
- **Где сохраняется корзина?** В localStorage до оформления; сервер перепроверяет данные и записывает заказ в PostgreSQL.
- **Почему нет настоящей оплаты?** Учебный режим безопасно демонстрирует сценарий без списания денег.
- **Как работает музыка?** Один аудиоэлемент в глобальном React Provider, кнопка в Header; браузер требует жест пользователя для звука.
- **Как работает карта?** Leaflet показывает тайлы OpenStreetMap и маркеры из координат API.
- **Что такое Redux?** Библиотека управления глобальным состоянием; в KONOK использован React Context, но для теоретического экзамена Redux изучается отдельно.

## Что изучать по порядку
1. `main.tsx` — маршруты и структура приложения.
2. `components/Layout.tsx` — шапка, навигация, карточки.
3. `lib/state.tsx` — глобальное состояние, корзина, звук.
4. `lib/api.ts` — API-запросы и типы.
5. `pages/Public.tsx` — каталоги и карточки.
6. `pages/Account.tsx` — регистрация, корзина, заказ.
7. `apps/api/src/index.js` — сервер и защита маршрутов.
8. `prisma/schema.prisma` — сущности и связи.
9. `pages/Admin.tsx` — редактирование контента.

**Говори только о реально работающих функциях после собственного тестирования.** Не называй иллюстративные исторические тексты проверенными и не утверждай, что онлайн-платёж реальный.
